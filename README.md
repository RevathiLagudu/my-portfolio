# Revathi Lagudu — Portfolio

Responsive personal portfolio for a Software Engineer / Java Developer.

Features: dark/light theme switch with saved preference, responsive navigation, About, Skills, Experience, Projects, Interview-ready profile, Education, Contact, resume download, LinkedIn/email links, animations and SEO metadata.

Run locally by opening `index.html` or using VS Code Live Server. Upload the folder to GitHub and deploy with Vercel (no build command required).
